# Security reports

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/jamditis/claude-peers-mcp/security/advisories/new). Include the affected version, steps to reproduce, impact, and any safe workaround. Do not post exploit details, tokens, credentials, private addresses, or message contents in a public issue.

For install, delivery, or federation failures without a security impact, use the matching public issue form. The [compatibility and support contract](docs/compatibility.md) states the current beta limits.
